# UX Research Graph Workspace — Documentation Pack

This folder contains the product and implementation specifications for the UX Research Graph Workspace MVP.

## Recommended reading order

1. `CODEX_INSTRUCTIONS.md` — rules Codex should follow before changing the codebase.
2. `SPEC.md` — product principles and overall architecture.
3. `MVP.md` — what must and must not be built in the first version.
4. `OBJECT_MODEL.md` — core objects and their responsibilities.
5. `DATA_MODEL.md` — suggested persistence model and relational schema.
6. `INTERACTIONS.md` — navigation, graph, selection, drag/drop, synthesis, and keyboard behavior.
7. `WORKSPACES.md` — detailed workspace behavior by object and study type.
8. `DESIGN_SYSTEM.md` — visual and interaction design system.
9. `BUILD_PLAN.md` — suggested implementation sequence and milestones.

## Product in one sentence

A graph-native UX research workspace that organizes research around business problems and preserves the reasoning path from research question to study, result, insight, and recommendation.

## Core principle

**Projects organize work. Graphs organize reasoning. Workspaces execute work.**

The core product must remain valuable without AI.
