1. Apply the migration in `supabase/migrations` to the linked Supabase project.
2. Create a Project with an initial Business Problem.
3. Verify the new Project opens with its initial node in the Graph.
4. Create several core object types and connect them by dragging between node handles.
5. Drag a node, reload the browser, and confirm its position persists.
6. Use an existing object UUID in a second Project and confirm it is attached by reference rather than duplicated.
